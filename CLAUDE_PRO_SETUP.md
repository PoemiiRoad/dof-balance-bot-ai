# Подключение личной подписки Claude Pro

Эта сборка использует Claude Agent SDK и подписочный OAuth-токен вместо
отдельно оплачиваемого Anthropic API. Режим рассчитан только на владельца
подписки: в `ALLOWED_USER_IDS` должен быть ровно один Telegram ID.

## 1. Получить OAuth-токен

Установите Claude Code на личном компьютере по официальной инструкции, войдите
в тот аккаунт, где активна подписка Pro, и выполните:

```text
claude setup-token
```

Откроется браузер. После подтверждения команда напечатает долгоживущий токен.
Не отправляйте его в Telegram, чат, GitHub или другим людям.

## 2. Настроить Railway или другой хостинг

В переменных окружения сервиса:

1. Удалите `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN`, если они есть.
2. Добавьте `CLAUDE_CODE_OAUTH_TOKEN` и вставьте полученный токен.
3. Добавьте `ALLOWED_USER_IDS` со своим числовым Telegram ID. Для AI должен быть
   указан ровно один ID.
4. Добавьте `AI_MODEL=sonnet`.
5. При необходимости задайте `AI_TIMEOUT_SECONDS=300`; это текущее значение по
   умолчанию и максимальный допустимый лимит этой сборки.

Токен храните как Secret. Реальное значение не должно попадать в `.env.example`
или репозиторий.

## 3. Файлы проекта

После обновления репозитория выполните новую сборку с `requirements.txt`.
`main.py`, `balance_logic.py` и `balance_monitor.py` должны использоваться из
одного и того же коммита.

## 4. Ресурсы контейнера

Claude Agent SDK запускает отдельный процесс. Не задавайте ресурсы контейнера по
этому документу вслепую: ориентируйтесь на фактическое потребление CPU/RAM и
логи вашего хостинга.

## 5. Проверка

1. В Telegram отправьте боту `/version`.
2. Ожидаемый ответ этой сборки: `2026.09.16-robust-ai-v3`.
3. Нажмите «Спросить AI» и сначала задайте короткий вопрос.
4. Для тяжёлого анализа смотрите в журнале строки `AI SYSTEM_PROMPT chars`,
   `AI context chars`, `AI total prompt chars`, `Claude first text_delta after`
   и итоговое время `Claude Agent stream completed after`.
5. В журнале не должно быть вызова старого `/v1/messages` или ошибки про
   `credit balance` от API-биллинга.

Если лимит Pro временно исчерпан, бот сообщит об этом отдельно. После окончания
или отмены подписки запросы через подписочный токен также перестанут работать.
