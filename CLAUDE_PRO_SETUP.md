# Подключение личной подписки Claude Pro

Эта сборка использует Claude Agent SDK и подписочный OAuth-токен вместо
отдельно оплачиваемого Anthropic API. Режим рассчитан только на владельца
подписки: в `ALLOWED_USER_IDS` должен быть ровно один Telegram ID.

## 1. Получить OAuth-токен

Установите Claude Code на личном компьютере по официальной инструкции, войдите
в тот аккаунт, где активна подписка Pro, и выполните:

```text
claude setup-token
```

Откроется браузер. После подтверждения команда напечатает долгоживущий токен.
Не отправляйте его в Telegram, чат, GitHub или другим людям.

## 2. Настроить Northflank

В переменных окружения сервиса:

1. Удалите `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN`, если они есть.
2. Добавьте `CLAUDE_CODE_OAUTH_TOKEN` и вставьте полученный токен.
3. Добавьте `ALLOWED_USER_IDS` со своим числовым Telegram ID. Если ID неизвестен,
   сначала запустите новую сборку без этой переменной, отправьте боту `/id`,
   скопируйте число, добавьте переменную и перезапустите сервис. Пока список
   пуст, AI-запросы заблокированы кодом.
4. Добавьте `AI_MODEL=sonnet`.
5. При желании добавьте `AI_TIMEOUT_SECONDS=90`.

Токен храните как Secret. Значение не должно попадать в `.env.example` или в
репозиторий.

## 3. Файлы проекта

Замените `main.py`, добавьте `requirements.txt`, затем выполните новую сборку и
перезапустите сервис. Файл `balance_logic.py` и остальные рабочие файлы проекта
оставьте без изменений.

## 4. Ресурсы контейнера

Claude Agent SDK запускает отдельный процесс. Для проверки начните с 1 vCPU,
1 GiB RAM и не менее 5 GiB диска. Текущего тарифа 0.1 vCPU / 256 MiB RAM может
не хватить: возможны медленная работа или завершение контейнера по памяти.

## 5. Проверка

1. В Telegram отправьте боту `/version`.
2. Ожидаемый ответ: `2026.09.10-claude-pro-v1`.
3. Нажмите «Спросить AI» и задайте короткий вопрос.
4. В журнале Northflank не должно быть вызова старого `/v1/messages` и ошибки
   про `credit balance`.

Если лимит Pro временно исчерпан, бот сообщит об этом отдельно. После окончания
или отмены подписки запросы через подписочный токен также перестанут работать.
